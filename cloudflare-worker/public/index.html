Self-hosted by design

Your key, your browser, your control.

Grammar Assistant does not require a shared SaaS account. Install the extension, choose a provider, paste your own API key locally, and start checking text. Provider free access depends on account, region, model, and current quota limits.

Keep keys private, start with free quota limits, and delete or rotate a key if it is exposed. Never publish API keys in GitHub, screenshots, or ZIP files.
