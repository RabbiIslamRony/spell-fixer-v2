Privacy policy

Grammar Assistant keeps setup local and user controlled.

This policy explains what the Chrome extension stores, what text it sends for grammar checking, and how the public landing page works.

Data stored by the extension

The extension stores settings, selected provider, site access preferences, and user-provided API keys in Chrome local extension storage on the user's device. API keys are not stored with Chrome sync.

Text sent for checking

When the extension is enabled, selected text or active editor text may be sent to the provider chosen by the user, such as Gemini, Qwen, or a custom external API. Page URL is sent only when the user turns on the Include page URL setting.

Third-party providers

Grammar Assistant does not provide a shared AI account. Users bring their own provider API key, and provider requests are subject to that provider's terms, privacy practices, quota, and billing rules.

Landing page demo

The public landing page demo is deterministic and runs in the browser. Demo text is not sent to Gemini, Qwen, or the Worker API.

Analytics, ads, and sale of data

The extension does not include advertising, affiliate tracking, analytics SDKs, or sale of user data.

User control

Users can disable the extension, clear API keys, restrict site access, or uninstall the extension at any time. API keys should be rotated with the provider if they are accidentally exposed.
