Self Hosted Grammar Assistant

This is an original extension. It sends text to your own API and displays the returned correction.

API request

POST /grammar/check
Content-Type: application/json
Authorization: Bearer optional-api-key

{
  "text": "This are a sentence.",
  "mode": "grammar",
  "language": "en",
  "pageUrl": "https://example.com",
  "context": ""
}

API response

{
  "correctedText": "This is a sentence.",
  "suggestions": [
    {
      "title": "Subject verb agreement",
      "replacement": "This is a sentence.",
      "explanation": "Use 'is' with singular 'This'.",
      "severity": "grammar"
    }
  ]
}

Usage

  1. Open the extension popup and turn Extension on.
  2. Focus a text box on any website.
  3. Start typing. The floating GA button appears only after typing pauses for a moment.
  4. Choose a red-underlined issue or replacement chip to apply a fix.
  5. Click outside the assistant UI to hide the suggestion bubble or full panel.

Pause suggestions

Use the Extension toggle in the popup to turn live suggestions off without deleting your API settings.

Site access

Use Advanced settings in the popup to allow all sites, block listed domains, or run only on listed domains.

Privacy

Text is sent only to the configured grammar API. Page URLs are not sent unless Include page URL is enabled. Worker QA text previews are disabled by default.
