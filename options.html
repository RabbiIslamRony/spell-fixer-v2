Self Hosted Grammar Assistant

This extension sends text to a hosted or self-hosted Cloudflare Worker. AI provider keys stay on the Worker, not in Chrome.

API request

POST /grammar/check
Content-Type: application/json
Authorization: Bearer worker-access-token

{
  "text": "This are a sentence.",
  "mode": "grammar",
  "language": "en",
  "scope": "panel",
  "pageUrl": "https://example.com",
  "context": ""
}

API response

{
  "correctedText": "This is a sentence.",
  "issues": [
    {
      "start": 0,
      "end": 8,
      "original": "This are",
      "replacement": "This is",
      "title": "Subject verb agreement",
      "explanation": "Use 'is' with singular 'This'.",
      "severity": "grammar"
    }
  ],
  "suggestions": []
}

Worker modes

  1. Use Hosted Worker when the admin gives you an access token.
  2. Use Custom Worker when you deploy your own Cloudflare Worker.
  3. Custom Worker requires the full /grammar/check URL and its matching token.

Usage

  1. Open the extension popup and turn Extension on.
  2. Focus a text box on any website.
  3. Start typing. The floating assistant button appears only after typing pauses for a moment.
  4. Choose a red-underlined issue or replacement chip to apply a fix.
  5. Click outside the assistant UI to hide the suggestion bubble or full panel.

Privacy

Text is sent only to the configured Worker. Page URLs are not sent unless Include page URL is enabled. Worker QA text previews are disabled by default.
